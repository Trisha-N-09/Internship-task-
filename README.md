# Task 2 - Data Visualization and Storytelling

This repository contains the files submitted for Task 2: Data Visualization and Storytelling.

## Files
- `Task_2_Data_Visualization_and_Storytelling.xlsx` — project dataset/workbook.
- `Task_2_Data_Visualization_and_Storytelling.pdf` — project/task reference document.

## Dataset
The workbook is based on sales/order data containing fields such as Order Date, Ship Date, Ship Mode, Customer, Segment, Location, Category, Sub-Category, Sales, Quantity, Discount, and Profit.

## Purpose
The project is intended for data visualization and storytelling using the provided sales data.
