# Task 4 — Dashboard Design

## Objective
Design an interactive dashboard for business stakeholders using the provided **Sample - Superstore.csv** dataset.

## Deliverables
- `dashboard/index.html` — interactive stakeholder dashboard
- `dashboard/dashboard_data.json` — aggregated dashboard data
- `presentation/Task_4_Dashboard_Summary.pptx` — PPT summary
- `data/Sample - Superstore.csv` — source dataset
- `README.md` — project documentation

## Dataset
- Records: 9,994
- Fields: 21 original fields plus helper date fields used for analysis
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Profit Margin: 12.5%

## Dashboard Features
- KPI cards: Sales, Profit, Orders and Profit Margin
- Year, Category, Region and Segment filters
- Monthly Sales and Profit trend
- Sales by Category
- Sales by Region
- Profit by Sub-Category

## How to Use
1. Upload this folder to a GitHub repository.
2. Open `dashboard/index.html` directly, or enable **GitHub Pages** for the repository.
3. Use the filters at the top to explore the dashboard.

## Business Insights
- Technology is the highest-sales and highest-profit category.
- West is the highest-sales region.
- Tables show negative profit and should be reviewed for pricing, discount and cost issues.
- Overall sales and profit increased from 2014 to 2017.
